Sauvegarder les données

Gardez une copie chiffrée de vos commandes, produits et dépenses. Faites-le chaque mois et avant de changer de téléphone.

↑

Restaurer une sauvegarde

Remplace les données synchronisées par celles d’un fichier de sauvegarde. Le mot de passe de ce fichier sera nécessaire.

▤

Exporter les commandes

Un fichier CSV lisible dans Excel ou Google Sheets pour partager votre registre de commandes.

✧

Code de récupération

À conserver en lieu sûr pour retrouver le compte si le mot de passe est oublié.

⌂

Installer sur le téléphone

Dans Safari, touchez Partager puis « Sur l’écran d’accueil ». Connectez-vous ensuite sur votre iPhone et votre iPad avec le même compte.

↪

Connexion sur un autre appareil

Déconnectez-vous pour afficher l’écran de connexion, puis connectez-vous sur cet appareil avec le même compte.

Conserver vos données. Elles sont chiffrées avant la synchronisation et restent accessibles avec le même identifiant et mot de passe sur vos appareils. Un appareil perdu ne supprime pas la copie en ligne. Faites aussi une sauvegarde mensuelle et gardez votre mot de passe : sans lui, les données chiffrées ne peuvent pas être récupérées. Une connexion Internet est nécessaire pour enregistrer les modifications.
